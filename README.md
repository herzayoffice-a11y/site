🚀 النشر على GitHub Pages
من إعدادات الريبو: Settings → Pages
اختر الفرع main والمجلد / (root)
احفظ، وانتظر دقيقة حتى يظهر رابط الموقع

تأكد أن مسارات الصور داخل index.html (مثل images/logo-mark.png) مطابقة تمامًا لأسماء الملفات الموجودة فعليًا داخل مجلد images/ (بحساسية حالة الأحرف Case Sensitive).
